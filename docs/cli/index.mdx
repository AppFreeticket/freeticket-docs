`ft` is the official FreeTicket CLI, published on npm as [`@freeticket/cli`](https://www.npmjs.com/package/@freeticket/cli). It calls the [B2B API](/guides) and gives you your events, sales, tickets, memberships, venues, staff, settlements and reports from the terminal. Output is a readable table, or JSON and CSV for scripts.

The CLI is generated from the API's OpenAPI contract, so its parameters and enums match the API.

## Requirements

- Node.js 20 or newer
- A FreeTicket account with access to a workspace

## Install

<CodeGroup>

```bash npm
npm install -g @freeticket/cli
```

```bash pnpm
pnpm add -g @freeticket/cli
```

```bash npx (no install)
npx @freeticket/cli@latest whoami
```

</CodeGroup>

Check the install:

```bash
ft --version
```

Run `ft` with no arguments, or `ft <command> --help`, to see what is available.

## First commands

```bash
ft signup --email you@example.com --name "Your Name"   # only if you have no account
ft login                               # browser login, no key to paste
ft whoami                              # your user and workspaces
ft events list                         # events across your workspaces
ft reports summary --period 30d        # KPIs for the last 30 days
ft sales list --status CONFIRMED --json
```

## Configuration

`ft` resolves settings in this order:

```text
flags  >  environment variables  >  ~/.freeticket/config.json  >  defaults
```

| Variable | Default | Purpose |
| --- | --- | --- |
| `FT_API_URL` | `https://admin.appfreeticket.com` | API base URL, without `/api/v1` |
| `FT_API_KEY` | | An `ft_live_…` key, for CI and headless use |
| `FT_WORKSPACE_ID` | | Default workspace id |
| `FT_NO_UPDATE_CHECK` | | Set it to turn off the "update available" notice |

`~/.freeticket/config.json` holds your stored accounts and their credentials, so the CLI writes it atomically with `0600` permissions (readable only by you). `ft config` shows the active configuration with credentials masked. With `FT_API_KEY` set, the CLI uses that single key and ignores the stored accounts.

When a newer version is on npm, `ft` prints an "update available" notice on stderr. It stays quiet with `--json`, `--raw` or `--csv`, outside an interactive terminal, in CI, and when `FT_NO_UPDATE_CHECK` is set. Update with `npm install -g @freeticket/cli@latest`.
