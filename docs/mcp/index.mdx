The FreeTicket MCP server exposes the platform as [Model Context Protocol](https://modelcontextprotocol.io) tools. Connect it to an AI assistant and ask in plain language, for example "how many tickets did we sell this week?", "publish the Medellín date" or "find a concert in Bogotá this Saturday". The assistant calls the right tool for you.

It is a client of the same [B2B](/guides) and [public](/guides/public-api) APIs as the CLI. Each tool maps to one API operation, with the same rules, roles and errors.

## Endpoints

The server is hosted. You don't need to install anything.

| URL | Auth | Tools |
| --- | --- | --- |
| `https://mcp.appfreeticket.com/mcp` | OAuth sign-in or an API key | Public tools plus your workspace's B2B tools |
| `https://mcp.appfreeticket.com/mcp/public` | None | Public tools only: discovery, availability and orders |

Both use the Streamable HTTP transport. The server is stateless: each request carries its own credential, and nothing is stored on the server.

## Safety

- The assistant can only do what **your role** allows in the workspace.
- Destructive tools (`*_delete`, `*_cancel`, `*_refund`) are marked destructive, so clients ask you to confirm them.
- The assistant never handles payments. Ordering tools return a payment link that the buyer opens.
- Tools can list API keys but not create or revoke them. Issuing credentials is left to you.
