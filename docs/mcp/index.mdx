The FreeTicket MCP server is the official [Model Context Protocol](https://modelcontextprotocol.io) server for FreeTicket, a ticketing platform for live events in Colombia and Latin America. It exposes the platform as tools, so an AI assistant can answer "how many tickets did we sell this week?", "publish the Medellín date" or "find a concert in Bogotá this Saturday" by calling the right tool for you.

It is a client of the same [B2B](/guides) and [public](/guides/public-api) APIs as the [CLI](/cli). Each tool maps to one API operation, with the same rules, roles and errors. Sign-in is OAuth 2.1 in the browser, so there is no key to paste.

## Endpoints

The server is hosted. You don't need to install anything.

| URL | Auth | Tools |
| --- | --- | --- |
| `https://mcp.appfreeticket.com/mcp` | OAuth 2.1 sign-in or an API key | Public tools plus B2B tools for your workspaces |
| `https://mcp.appfreeticket.com/mcp/public` | None | Public tools only: discovery, availability and orders |

Both use the Streamable HTTP transport. The server is stateless: each request carries its own credential (an API key, or an OAuth token that seals one), and the server keeps no database. The manifest is published at `https://appfreeticket.com/.well-known/mcp.json`.

## Safety

- The assistant can only do what **your role** allows in the workspace.
- Destructive tools (`*_delete`, `*_cancel`, `*_refund`) are marked destructive, so clients ask you to confirm them.
- The assistant never handles payments. Ordering tools return a payment link that the buyer opens.
- Tools can list API keys but not create or revoke them. Issuing credentials is left to you.
- For analysis-only agents, connect with a `read`-scoped API key so write tools fail instead of acting.
